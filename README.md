# CAVEMAN力训馆

基于单个 HTML 文件的力量训练计划记录工具，纯前端，数据保存在访问者浏览器本地（localStorage）。

站点标题为 **CAVEMAN力训馆**；`index.html` 已配置完整的 Open Graph / 微信分享元信息，分享到微信或浏览器时显示该标题与 `share-thumb.jpg` 缩略图（取自用户上传的深蹲照片）。

首页模块自上而下：**我的教练**（JTS / SBS 理论知识与动作知识）、**当前使用计划**、**计划选择**、**快速搜索**、页脚、**导出备份**（页面最底端）。**主流体系**与**拓展阅读**的具体内容不在首页展示，仅保留在顶部导航条，点击进入各自的子界面。计划介绍补充了各计划的体系依据与资料出处。

## 页面结构

- **打开链接（含带 `#plan=` 等 hash 的旧链接）一律默认进入主页**，不自动跳进上次训练计划；老用户可在主页「当前使用计划」面板点「继续训练」一键回到计划。
- 顶部导航条四项：**我的教练、计划介绍、主流体系、拓展阅读**（「计划选择」为首页模块，不在导航条）。**「我的教练」「主流体系」「拓展阅读」「计划介绍」及其所有逐级下钻的子界面，顶部都会保留这条四项导航条**，可随时互相切换；仅训练计划页（日历 / 训练日 / 记录）为沉浸式阅读而隐藏顶栏，返回主页即恢复。
- 首页模块顺序：**我的教练 → 当前使用计划 → 计划选择 → 快速搜索 → 页脚 → 导出备份**。
- 「我的教练」「主流体系」「计划介绍」页的说明 / 简介段落已移除，直接呈现卡片与内容。
- **快速搜索**：位于首页「计划选择」下方，输入问题或关键字（如「深蹲膝盖内扣怎么办」「RPE 怎么用」「减载怎么安排」）即时检索全站知识库——我的教练（JTS / SBS 理论与动作知识）、主流体系、拓展阅读书目与章节要点、计划介绍。中文长问句自动切词，结果按相关度排序并保底覆盖每个命中的分类，命中词高亮；点击结果跳转到对应子界面并滚动高亮定位原文；返回主页后保留上次的检索词与结果。附 10 个常用关键词快捷标签、回车触发、清空按钮。
- **主流体系**：子界面先展示 4 个体系模块（JTS / SBS / RTS 反应式训练系统 / 共轭法 · 西部杠铃），点击模块进入下一级界面展开该体系的完整梳理（核心要点 + 依据资料）。
- **拓展阅读**：子界面先展示按体系分组的 10 部书目，点击书目进入该书的章节模块列表，再点击章节进入下一级界面展开该章要点（含上一章 / 下一章翻页与本书章节目录）。JTS 与 SBS 书目优先排列，合计 150 章 722 条要点。
- **计划介绍**：子界面默认只展示每张计划的概况（训练周期、每周频次、一句话简介），点「展开详情 ↓」才展开该计划 7 项完整内容（适应人群、适用阶段、计划特点、底层逻辑、体系依据 · 资料出处、优势、局限）；从主页「查看计划介绍」跳转时自动展开对应卡片。
- **导出备份**为首页最底端的单个按钮（无面板与说明文字）；数据仅存于浏览器本地，换设备或清除缓存前请导出 JSON 文件妥善保存。
- 各页面「返回主页」按钮已加粗加大，更醒目；子界面另提供「返回体系列表 / 返回书目 / 返回本书目录」。

## 说明

- 计划选择排序：Juggernaut → RTS 系列 → Russwole → The 74kg → SSTT → CATS 系列 → 古斯塔夫 → 腰王系列 → 其余计划。
- 训练重量统一按 2.5kg 向上取整。
- 组间休息计时器支持 60–300 秒自定义，可开始 / 暂停 / 清零。
- 「重新开始训练」位于训练日历工具栏，二次确认后清空该计划的全部记录（组记录、总结、计时、动作归类、计划总评），训练极限设置会保留。
- 「三大项极限预测」按 估算 1RM ＝ 重量 ×（1 ＋ 次数 × 0.0333）取计划内强度最高的完成组，并与最初输入的计划极限对比，显示差异（kg 与 %）。
- 「我的教练」「主流体系」「拓展阅读」知识点全部依据上传资料原文整理。
