# Caveman力训馆

基于单个 HTML 文件的力量训练计划记录工具，纯前端，数据保存在访问者浏览器本地（localStorage）。

内置「我的教练」知识库：JTS（Juggernaut / 力量训练原理）与 SBS（Stronger By Science）两大体系，各分理论知识与动作知识（动作知识为重点）；教练页下方另有「各体系总结简介」，把上传资料按 JTS、SBS、RTS 反应式训练系统、西部杠铃共轭法四类梳理成体系定位、核心主张、训练编排与代表文献。计划介绍补充了各计划的体系依据与资料出处。

## 说明

- 数据仅存于浏览器本地，换设备或清除缓存会丢失，请使用**首页底部的「导出备份」**按钮导出 JSON 备份文件妥善保存。
- 训练重量统一按 2.5kg 向上取整。
- 组间休息计时器支持 60–300 秒自定义，可开始 / 暂停 / 清零。
- 每个训练计划附带时长、每周频率、适用阶段与训练特点说明。
- 「重新开始训练」位于训练日历工具栏，二次确认后清空该计划的全部记录（组记录、总结、计时、动作归类、计划总评），训练极限设置会保留。
- 「三大项极限预测」按 估算 1RM ＝ 重量 ×（1 ＋ 次数 × 0.0333）取计划内强度最高的完成组，并与最初输入的计划极限对比，显示差异（kg 与 %）。
- 「我的教练」知识点全部依据上传资料原文整理：《计划致胜》不属于 SBS 体系且其 PDF 无可提取正文，故未纳入 SBS 教练模块。
