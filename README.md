# 力量训练计划追踪 · Training Journal

基于单个 HTML 文件的力量训练计划记录工具，纯前端，数据保存在访问者浏览器本地（localStorage）。

## 在线地址

- 训练计划追踪（首页）：https://hw2421.github.io/strength-training-journal/
- 山顶洞人力训教练：https://hw2421.github.io/strength-training-journal/coach.html

微信扫码分享卡：`微信二维码_分享卡.png`

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 力量训练计划追踪（完整计划介绍版）：计划选择、**计划介绍（周期 / 频率 / 阶段 / 特点）**、训练日历、逐组记录、训练计时器、**组间休息计时器**、负荷统计、每日总结 |
| `coach.html` | 山顶洞人力训教练 |
| `.nojekyll` | 关闭 GitHub Pages 的 Jekyll 处理 |

## 说明

- 数据仅存于浏览器本地，换设备或清除缓存会丢失，请使用页面内的「导出备份 / 恢复备份」。
- 训练重量统一按 2.5kg 向上取整。
- 组间休息计时器支持 60–300 秒自定义，可开始 / 暂停 / 清零。
- 每个训练计划附带时长、每周频率、适用阶段与训练特点说明。
